# CHUKAEV LAB — сайт для GitHub Pages

## Что внутри
- `index.html` — сайт: тренды, поиск, категории, промпты, обучение, KVANTYRA AI.
- `styles.css`, `app.js` — оформление и работа каталога.
- `templates.json` — **единый файл всех шаблонов**. Изначально содержит 32 названия из Telegram-навигации; ссылки и MP4 ещё нужно добавить. Ничего не выдумано.
- `admin.html` — мобильный редактор каталога (без сервера и без GitHub-токена).
- `assets/videos/` — сюда загружаются MP4.
- `assets/brand/kvantyra.png` — логотип KVANTYRA AI.

## Запуск
1. Создайте **отдельный тестовый репозиторий** GitHub, чтобы не затронуть действующий сайт.
2. Загрузите содержимое папки `CHUKAEV-LAB` **в корень** репозитория.
3. В `Settings → Pages` выберите `Deploy from a branch`, `main`, `/ (root)`.
4. Откройте адрес GitHub Pages. Важно: открытие `index.html` прямо из файлов телефона может не загрузить JSON из-за ограничений браузера.
5. После проверки замените действующий сайт, если захотите.

## Добавить новый шаблон с телефона/планшета
1. На GitHub откройте свой репозиторий → `assets/videos` → `Add file` → `Upload files`, загрузите `my-video.mp4` (через браузер GitHub до 25 МиБ на файл).
2. Откройте опубликованную страницу `https://ВАШ-САЙТ/admin.html`.
3. В блоке «Выбрать видео с GitHub» укажи владельца и репозиторий, нажми «Показать видео» и выбери загруженный MP4. Его имя автоматически появится в форме. Затем введи название, категорию и **прямую ссылку на конкретный шаблон**. Если репозиторий приватный, впиши имя файла вручную.
4. Нажмите `Добавить в каталог`, затем `Скачать templates.json`.
5. На GitHub в корне репозитория откройте `templates.json` → карандаш Edit. Чтобы заменить содержимое, откройте скачанный файл в текстовом редакторе телефона, скопируйте весь текст и вставьте вместо старого; нажмите `Commit changes`.
   - Если в интерфейсе GitHub доступна замена файла через Upload files, можно загрузить скачанный `templates.json` с тем же именем вместо редактирования.
6. Подождите обновления GitHub Pages, затем обновите страницу.

**Важно:** `admin.html` не сохраняет изменения на GitHub автоматически, потому что для этого нужен защищённый сервер с авторизацией. Не вставляйте GitHub-токены в публичные файлы сайта.

## Два видео старого сайта
Они пока не включены в архив, потому что исходные MP4 не были прикреплены. Положите их под точными именами:
- `assets/videos/kvantyra-guide.mp4`
- `assets/videos/kvantyra-install.mp4`

## Заполнение существующих карточек
32 записи в `templates.json` пока без `video` и `url`: они отображаются с заглушкой и без активной кнопки. Для них нужно проставить видео и ссылки. Откройте `admin.html`, нажмите «Изменить» напротив существующей записи, заполните имя MP4 и ссылку, затем «Добавить в каталог» и скачайте обновлённый JSON.

## Эксплуатация
Видео загружаются только при взаимодействии с плеером (`preload=none`); автозагрузка всей ленты не выполняется. Для большого трафика предусмотрите перенос MP4 на отдельный хостинг. GitHub Pages имеет правила и ограничения на преимущественно коммерческое использование и трафик; это не гарантия разрешения такого сценария. Сохраняйте резервную копию репозитория.
