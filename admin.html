Редактор шаблонов.

Добавляй новые тренды с телефона или планшета. Вводи название MP4, категорию и ссылку на нужный шаблон — без правки кода.

Это локальный редактор без пароля и доступа к GitHub. Изменения появятся на сайте только после загрузки скачанного templates.json в репозиторий. Не вставляй сюда токены GitHub или пароли.

1. Каталог

При открытии с опубликованного сайта текущий каталог загрузится автоматически. Если открыл редактор из файлов телефона, выбери существующий templates.json вручную.

Загружаем каталог…

2. Выбрать видео с GitHub

Для публичного репозитория: введи владельца и название репозитория, затем нажми «Показать видео». Выбери нужный файл — имя MP4 автоматически подставится в форму ниже. Пароль и токен не нужны.

4. Сохранить изменения

Скачай готовый файл и загрузи его в корень репозитория GitHub с заменой старого templates.json. Видео отдельно положи в assets/videos/.

Важно: пока нет файла MP4 или прямой ссылки, карточка будет отображаться как заготовка, без неработающей кнопки. Указанные ссылки должны вести именно на нужный шаблон, а не на общий бот.
